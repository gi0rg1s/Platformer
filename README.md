# JOJO RUNNER

A fun and addictive endless runner game inspired by the Chrome Dinosaur game, built with Python and Pygame. Jump over obstacles and try to beat your high score!

*Made by Gizzi Manuel and Folloni Giorgia*

---

## 🎮 Description

**JOJO RUNNER** is a great, mini, and very simple game. It's perfect for playing alone or challenging your friends to see who can get the highest score. Featuring dynamic sprites and energetic music, it captures the classic runner game feel with a unique style.

## ✨ Features

### ✅ Already Implemented
*   **Core Gameplay:** Smooth running and jumping mechanics.
*   **Visuals & Audio:** Main character sprites and background music.
*   **Technical Foundation:** FPS control for consistent performance and hitbox detection for accurate collisions.

### 🚧 Planned Features
*   **Easter Egg:** Stay tuned for a hidden surprise! 🥚
*   **Final Scoreboard:** View your score at the end of each run.
*   **Character Selection:** Choose from multiple main characters.
*   **More Content:** Additional sprites and music tracks.
